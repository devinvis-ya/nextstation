# «Следующая станция…» — Design Spec

**Дата:** 2026-05-08
**Источник:** `prompt.md` (ТЗ от пользователя) + уточнения через brainstorming.

## Цель

Атмосферный Lo-Fi симулятор / экзистенциальный кликер. Пользователь смотрит «в окно купе» едущего поезда, видит бесконечно сменяющиеся города на табло и слышит стук колёс. Ключевая фишка — петля: при достижении станции назначения название города на табло подменяется случайным городом России и поездка начинается снова.

## Зафиксированные решения (по итогам brainstorming)

| Тема | Решение |
|---|---|
| Подход к реализации | Всё одним проходом (без чек-поинтов между шагами ТЗ). |
| Визуальный стиль | Inline SVG-иллюстрации, ламповая векторная стилистика. Без внешних ассетов. |
| Звук | Web Audio API, программный синтез стука колёс. Без внешних аудиофайлов. |
| Расположение проекта | Корень `/mnt/c/Idea/NextStation/`, рядом с `prompt.md`. |
| Длительность поездки | 60 секунд при 1×, переключатель скорости 0.5× / 1× / 2× / 5×. |
| Время суток | Авто-смена по прогрессу + переключение по клику на окно (клик перебивает авто до конца петли). |
| Персистентность | Нет (свежий запуск каждый раз, без localStorage). |
| Язык | TypeScript. |

## Технологический стек

- **Build:** Vite (template `react-ts`).
- **UI:** React 18 + Tailwind CSS 3.
- **Анимации:** Framer Motion.
- **Иконки:** lucide-react.
- **Состояние:** локальные React-хуки (`useState`, `useEffect`, `useRef`, `useReducer` где удобнее).
- **Звук:** Web Audio API (нативный, без библиотек).

Никаких внешних API/CDN, никаких изображений с диска — всё inline.

## Состояние приложения

Управляется в `App.tsx` через хуки `useJourney`, `useTimeOfDay`, `useTrainSound`. Передаётся компонентам через props (без context — глубина вложенности невелика).

| Поле | Тип | Источник | Описание |
|---|---|---|---|
| `progress` | `number` (0–100) | `useJourney` | Авто-инкремент через `requestAnimationFrame`. |
| `speed` | `0.5 \| 1 \| 2 \| 5` | `App` (`useState`) | Множитель темпа. Влияет на скорость прогресса, параллакса и звука. |
| `currentCity` | `string` | `useJourney` | Стартовое значение `'Сергиев Посад'`. |
| `previousCity` | `string \| null` | `useJourney` | Предыдущая станция назначения (для возможного UI). |
| `tripCount` | `number` | `useJourney` | Сколько раз случилась подмена. Стартует с 0. |
| `timeOfDay` | `'day' \| 'sunset' \| 'night'` | `useTimeOfDay` | Эффективная фаза. |
| `manualOverride` | `boolean` | `useTimeOfDay` (внутри) | true после клика; сбрасывается при подмене. |
| `isGlitching` | `boolean` | `useJourney` | true когда `progress >= 95`. |
| `isMuted` | `boolean` | `useTrainSound` | Управление звуком. |

## Логика петли (`useJourney`)

Один `requestAnimationFrame` цикл:

```
loop(timestamp):
  dt = (timestamp - lastTimestamp) / 1000        // сек
  delta = dt * speed * (100 / DURATION_BASE_SEC) // % за кадр
  progress = min(100, progress + delta)

  if progress >= 95 && !isGlitching: setIsGlitching(true)

  if progress >= 99 && !inSwap:
    inSwap = true
    nextCity = randomFrom(cities, exclude=currentCity)
    setPreviousCity(currentCity)
    setCurrentCity(nextCity)
    setTripCount(n => n + 1)
    setProgress(randomBetween(5, 10))
    setTimeout(() => { setIsGlitching(false); inSwap = false }, 600ms)
```

Константы:
- `DURATION_BASE_SEC = 60` — длительность одной петли при `speed = 1`.
- При `speed = 5` петля ≈ 12 секунд, при `speed = 0.5` ≈ 120 секунд.
- Окно глитча: 95–100% прогресса + 600 мс после сброса.

Чистка: при unmount компонента `cancelAnimationFrame` + `clearTimeout`.

## Время суток (`useTimeOfDay`)

- **Авто-фаза** считается из `progress`: `<33` → `day`, `33–66` → `sunset`, `≥66` → `night`.
- **Клик по окну** циклически переключает: `day → sunset → night → day`. Клик ставит `manualOverride = true` и фиксирует выбранную фазу до конца петли.
- При подмене города `manualOverride` сбрасывается → авто-фаза возобновляется.
- Эффективное значение: `manualOverride ? manualPhase : autoPhase`.

Переход между фазами анимируется через CSS-переменные палитры на `<body>` или корневом `<div>` (`--color-sky-top`, `--color-sky-bot`, `--color-forest`, …) с `transition: background-color 1.2s ease`.

## Параллакс (`ParallaxLayer` + `TrainWindow`)

`ParallaxLayer` принимает: `children` (SVG), `speedFactor` (0.05 / 0.3 / 1.0), `width` (ширина одного экземпляра в px).

Рендерит обёртку с двумя экземплярами children подряд, оборачивает в `motion.div` с:
```
animate={{ x: [0, -width] }}
transition={{ duration: width / (BASE_PX_PER_SEC * speedFactor * speed),
              ease: 'linear', repeat: Infinity }}
```

`BASE_PX_PER_SEC` подобрать так, чтобы при `speed=1` слой `poles` (factor 1.0) проходил экран ≈ за 4 секунды.

Слои сверху вниз внутри `TrainWindow`:
1. Sky (factor 0.05) — почти неподвижное небо/градиент.
2. Forest (factor 0.3) — холмы/лес дальнего плана.
3. Poles (factor 1.0) — столбы и редкие деревья у путей.

## Интерьер (`Interior`)

Статичный слой поверх `TrainWindow`:
- `WindowFrame` — толстая рамка вагонного окна (тёплый цвет).
- `Table` — столик у окна.
- `TeaGlass` — стакан в металлическом подстаканнике (кликабелен).
- `LeraSilhouette` — силуэт сидящей девочки в нижнем-правом углу, смотрит в окно (полупрозрачный, темнее интерьера).

При клике на `TeaGlass` рендерится `<Steam>` с уникальным ключом — поднимающиеся колечки пара (3 SVG-эллипса, opacity 0→1→0, y: 0 → -40px, длительность 2с). По окончании анимации компонент удаляется. Несколько кликов = несколько одновременных «облачек».

## Глитч (`GlitchText`)

Получает `text` и `isGlitching`. Когда `isGlitching = true`:
- Каждые 80 мс заменяет случайные ~30% символов на случайные кириллические/латинские буквы (на 50 мс), затем возвращает.
- Рендерит ещё две абсолютно позиционированные копии текста: red (`#ff3030`, сдвиг −2px по X) и cyan (`#30e0ff`, сдвиг +2px по X) с `mix-blend-mode: screen`.
- Лёгкий jitter родительского `<span>`: Framer Motion `animate={{ x: [-1, 1, -1, 0] }}` repeat infinity, 120 мс.

Когда `isGlitching = false` — обычный оранжевый текст без эффектов.

## Цветовая палитра (`theme/palette.ts`)

  reflection: string; // тёплый оверлей на стекле

Значения:
| Phase | skyTop | skyBot | forest | interior | lamp |
|---|---|---|---|---|---|
| day | `#a8c4d9` | `#dbe7ee` | `#5e7a5e` | `#7a5a3a` | `#f0d090` |
| sunset | `#e8a070` | `#7a5080` | `#3a4a55` | `#5a3a28` | `#ff9a50` |

## Звук (`useTrainSound`)

Реализация на `AudioContext`:
- Контекст создаётся **лениво** при первом пользовательском жесте (клик по окну/стакану/спид-селектору) — иначе браузер заблокирует.
- Источник стука: short-burst lowpass-filtered noise (`BufferSource` с белым шумом, длительность 60мс, lowpass ~ 250Hz, `GainNode` envelope: 0 → 0.6 → 0 за 60мс).
- Паттерн «тук-тук … тук-тук»: два удара с интервалом 80мс, затем пауза 700мс / `speed`.
- Планировщик: `setInterval` или цепочка `setTimeout`, использующая `audioContext.currentTime` для точного тайминга.
- `MuteButton` управляет master `GainNode` (gain 0/0.7).
- Cleanup: при unmount закрыть контекст, отменить таймеры.

## UI-управление

- `SpeedSelector` (правый верх): четыре пилюли `0.5× / 1× / 2× / 5×`, активная подсвечена.
- `MuteButton` (правый низ): иконка `Volume2`/`VolumeX` из lucide-react.
- Никаких других панелей. tripCount можно показать мелким текстом в углу или вообще скрыть (опционально, склонимся к мелкому тексту «петля #N»).

## Ошибки и edge cases

- Web Audio запрещён до жеста — отлавливаем, ничего не падает; звук просто не стартует, mute-кнопка ничего не делает пока пользователь не взаимодействует. После первого клика — стартует.
- `requestAnimationFrame` поставлен на паузу когда вкладка скрыта (нативное поведение). При возврате — `lastTimestamp` будет старым; в первом кадре после возврата `dt` обнуляется (если `dt > 0.5s`, считаем `dt = 1/60`), чтобы прогресс не «прыгал» вперёд.
- Resize окна: параллакс — фиксированной ширины SVG, дублируется. Если экран шире — три экземпляра вместо двух (рассчитать на основании `window.innerWidth`).
- Очень маленький viewport (<400px): пропорционально уменьшаем интерьер и табло. Минимальный размер шрифта — 12px.

## Не входит в scope

- Мобильные жесты (свайпы), геолокация, реальные звуки, мультиплеер.
- Сохранение состояния между сессиями.
- Полноценное меню/настройки (только speed + mute).
- Локализация (UI только на русском).
- Тесты (для UI-проекта такого размера TDD не требуется; визуальная проверка в браузере).

## Критерии приёмки

1. `npm install && npm run dev` стартует Vite, открывается страница без ошибок в консоли.
2. Видны три параллакс-слоя, движутся с разной скоростью.
3. Видны рамка окна, столик, стакан, силуэт Леры.
4. Верхнее табло показывает «СЛЕДУЮЩАЯ СТАНЦИЯ: СЕРГИЕВ ПОСАД», прогресс-бар внизу.
5. Прогресс-бар заполняется за ~60 секунд при `speed=1`.
6. На 95–100% табло глитчит.
7. На сбросе город меняется на случайный из списка, прогресс откатывается к 5–10%, петля продолжается бесконечно.
8. Клик по стакану — поднимается пар.
9. Клик по окну (не по стакану) — циклически day/sunset/night, цвета переходят плавно.
10. Speed selector переключает темп прогресса, параллакса и стука колёс.
11. Mute глушит звук.
12. Web Audio стартует только после первого пользовательского жеста, без ошибок в консоли.
