ТЗ для проекта "Бесконечный поезд в Сергиев Посад"


1. Общее описание
Название: "Следующая станция..."
Жанр: Атмосферный Lo-Fi симулятор / Экзистенциальный кликер.
Сеттинг: Вид из окна купе поезда дальнего следования. В центре сюжета — девочка Лера, которая едет домой из Москвы в Сергиев Посад.
Главная фишка: Когда прогресс поездки достигает финала, город на табло меняется на случайный город России, и путь начинается заново.

2. Технологический стек
Framework: React + Vite.

Styling: Tailwind CSS.

Animations: Framer Motion (для параллакса и переходов).

Icons: Lucide-react.

State Management: React Hooks (useState, useEffect).

3. Архитектура компонентов
App.tsx: Корневой компонент, хранит глобальное состояние (прогресс, текущий город, время суток).

TrainWindow: Основная визуальная часть. Реализует многослойный параллакс-фон (дальний план, средний план, ближний план).

Interior: Статичный слой поверх окна (рамка окна, столик, стакан в подстаканнике, силуэт Леры).

StatusBar: Верхнее табло в вагоне и нижний индикатор прогресса.

SoundEngine: Логика воспроизведения звука поезда (loop).

4. Игровые механики и логика
Движение: Полоска прогресса заполняется автоматически. Скорость зависит от переменной speed.

Событие "Подмена":

Когда progress достигает 95%, на табло начинаются визуальные помехи (эффект глитча).

На 99% город "Сергиев Посад" заменяется на случайное значение из массива russianCities.

progress сбрасывается не в 0, а в 5-10% (плавный откат), создавая петлю.

Интерактив (Optional):

При клике на стакан — идет пар.

При клике на окно — меняется время суток (день/закат/ночь).

5. Визуальные требования
Параллакс: * Слой 1 (небо): Движется очень медленно.

Слой 2 (лес/горы): Движется со средней скоростью.

Слой 3 (столбы/деревья у путей): Пролетают быстро.

Цветовая палитра: Приглушенные, "ламповые" тона. Текст на табло — ярко-оранжевый или зеленый (как в старых вагонах).

6. Массив данных (Города)
Подготовить список из ~50-100 городов России (от Калининграда до Владивостока).

Рекомендация по запуску в Claude Code:
Чтобы Claude Code выдал лучший результат, вводи задачи итерациями.
